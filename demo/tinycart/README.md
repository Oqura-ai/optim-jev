# TinyCart

TinyCart is a deliberately small, standard-library-only Python project used to demonstrate all three optim-jev tools in one Claude Code session.

The project has three kinds of work:

- inventory audits, guided by a project skill;
- low-risk documentation and report edits;
- pricing code, protected by stricter router rules.

Run its tests with:

```text
python run_tests.py
```

For the recording script and exact prompts, see [DEMO.md](DEMO.md).
